Problem:
Manual web application testing was time‑consuming and error‑prone in my coursework, especially for login flows and repetitive test cases.

Contribution: 
I designed and implemented an automated testing framework using Java + Selenium WebDriver inside Eclipse.
I wrote modular test scripts (LoginTest.java, TestReport.java) and documented the testing process in TestPlan.md. 
I also generated automated reports to track results over multiple runs.

Stack:
Java (OOP principles)
Selenium WebDriver for browser
automation JUnit for test execution
Markdown for test documentation

Result:
The automation reduced repetitive manual testing, produced consistent reports, and helped validate login functionality faster. 
It also served as a portfolio project demonstrating my ability to set up a structured automation environment.
