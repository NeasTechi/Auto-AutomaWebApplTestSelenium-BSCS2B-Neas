# TEST PLAN: Automated Web Application Testing Using Selenium

## 1. Test Item
- Application: Demo Login Page (https://www.saucedemo.com/)
- Reason: Public test site with proper login functionality

## 2. Features to be Tested
- Username input field
- Password input field
- Login button
- Error message handling
- Page navigation after login

## 3. Testing Techniques Used
- **Black Box Testing**: Test functionality without internal code knowledge
- **White Box Testing**: Analyze HTML structure for element identification
- **Grey Box Testing**: Combine UI behavior with HTML structure analysis

## 4. Tools & Technologies
- Selenium WebDriver 4.38.0
- ChromeDriver for Chrome browser
- Java 17
- Eclipse IDE

## 5. Test Environment
- OS: Windows 11
- Browser: Chrome 143+
- Java: JDK 17
- Selenium: 4.38.0

## 6. Expected Output
- Pass/Fail results for each test scenario
- Console logs with detailed results
- Screenshot on test failure (optional enhancement)
